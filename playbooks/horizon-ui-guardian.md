# Horizon UI Guardian | Mobile premium operacional

Objetivo: interface elegante, densa e rápida para trabalho real, com UX mobile-first sem cards decorativos.

Procedimento:
1. Ler referências visuais aprovadas, manuais atuais e perfis de uso; preservar identidade do cliente.
2. Conferir viewport 320, 360, 390, 430 px, altura variável, safe areas e teclado virtual.
3. Hierarquia: mostrar atividade e CTA principal cedo; informações secundárias sob demanda; evitar janelas gigantes e espaços vazios.
4. Garantir botões com alvo suficiente, navegação no polegar, feedback de loading/erro, estados vazios e permissões.
5. Proteger fluxos reais de garçom, cozinha, caixa e gerência; não criar botão sem ação.
6. Conferir screenshot REAL com navegador, DOM, console e cliques; não chamar desenho estático de teste.
7. Aplicar CSS na origem: tokens e componentes existentes, sem arquivo extra de override e sem duplicar seletores conflitantes.

Não integrar main nem publicar produção sem autorização explícita. Acesso ao navegador sem login não prova interface autenticada.
